# Tsumugi キーバインド一覧

標準設定のキーを、使う画面・モードごとにまとめた一覧です。
基本の使い方は [日本語ガイド](guide.ja.md)、全アクション名と割り当ては
[英語の生成リファレンス](spec/reference/keys.md)、設定形式は [キー仕様](spec/keys.md) を参照してください。
設定を変更している場合は、アプリの `F1` と Settings のキー設定で現在の割り当てを確認できます。

## 表記と、キーが有効になる条件

| 表記 | 意味 |
| --- | --- |
| `Ctrl+x` | Ctrl と x を同時に押す |
| `Ctrl+q h` | Ctrl+q を押してから h を押す。以降も空白は順番に押す意味 |
| `g g` | g を2回押す |
| `G` / `g` | 大文字は Shift+g。大文字・小文字を区別する |
| `Plus` | `+` の文字を入力するキー |
| `Mod` | macOS では Command、Linux / Windows では Ctrl+Shift |
| `Esc` | Escape キー |

たとえば `Mod+p` は Linux / Windows では `Ctrl+Shift+p`、macOS では `Cmd+p` です。
`Mod+]` のような記号も Linux / Windows では Shift を含みます。
`Ctrl+q h` は Ctrl を押したまま `Ctrl+q Ctrl+h` と押しても使えます。

キーの送り先は画面左下のモード表示で確認します。

| 場所・状態 | キーが届く先と注意点 |
| --- | --- |
| Tree / Agents | 左サイドバーの、フォーカスがある一覧。両者の選択・絞り込みは別々 |
| Prompt | 下側の Neovim 入力欄。通常は Neovim の操作。挿入モードでも送信などの専用キーが使える |
| Console | 上側のエージェント画面。下記のコンソール用キーを処理し、未割り当てのキーで出力の閲覧を始める |
| コンソールの閲覧中 | 出力を読む Neovim。ノーマルモードで閲覧終了用キーが使える |
| DIRECT | 手動でキーを直接送るモード。`Ctrl+q` もエージェントへ届く。`Esc` で解除 |
| PASS | シェルや、エージェントへの応答中の表示。中のプログラムの操作を使う |
| 許可待ち・エージェント自身のダイアログ・起動直後の応答待ち | 入力欄にいても通常のキーはエージェントへ届く。質問への応答を終えると入力欄へ戻る |
| シェル / ファイル編集用 Neovim | 中のプログラムのキーを使う。下側の依頼入力欄はない |
| ピッカー・確認ダイアログ・キーヘルプなど | 開いているものがキーを受け取り、背後の画面は操作されない |
| 検索・名前変更などの文字入力欄 | 文字キーは入力になる。`j` / `k` / `q` も文字として入力される |

共通操作の `Mod` / Command キーと `Ctrl+q` からの操作は、通常は入力欄の挿入モードや
シェルでも使えます。DIRECT 中の `Ctrl+q` は直接送信されます。
文字入力欄やピッカーなどが開いている間は、その入力・選択操作を先に終えてください。
macOS のコピー・貼り付け・終了など、メニューバーが扱う Command キーは OS の操作です。

## まず使う共通操作

| キー | 操作・条件 |
| --- | --- |
| `F1` | 有効なキー一覧。入力欄の挿入モードでも使える。DIRECT 中は直接送信される |
| `Mod+p` | セッションへ移動、または作業フォルダーを選んで新規作成 |
| `Mod+t` | 現在の作業場所に新規セッションの下書きを開く。Tree では選択行の場所を使う |
| `Mod+s` | 作業場所にシェルを開く |
| `Mod+e` | 作業場所に普段の設定の Neovim を開く |
| `Mod+o` | Claude Code / Codex の保存済み会話を探して再開 |
| `Mod+j` / `Mod+k` | 応答待ち → 未読 → ツリー順の優先で、次 / 前のセッションへツリーのカーソルを移す |
| `Ctrl+q }` / `Ctrl+q {` | 次 / 前のワークスペースのセッションへ移動 |
| `Mod+Backspace` | セッションや対象ターミナルを確認後に終了 |
| `Mod+f` | サイドバーの一覧を絞り込む。`Enter` で確定、`Esc` で解除 |
| `Mod+r` | セッションや Git の状態を再取得 |
| `Mod+b` / `Mod+d` | 左サイドバー / 右の詳細パネルの表示切り替え |
| `Mod+,` | Settings を開く |
| `Mod+=` / `Mod+Plus` / `Mod+-` | アプリ全体を拡大 / 拡大 / 縮小 |
| `Mod+0` | アプリ全体の表示倍率を設定値に戻す |
| `Mod+n` | 同じインスタンスの別ウィンドウを開く |
| `Cmd+Shift+w` | macOS：アプリのウィンドウを閉じる |

## 入力欄：依頼を書く・送る

下側の Prompt にフォーカスがあるときの操作です。許可待ちなどの直接応答中を除きます。
通常の文字入力・編集・検索は Neovim の操作を使います。

| キー | 操作・条件 |
| --- | --- |
| `i` / `a` | ノーマルモードから挿入モードへ |
| `Esc` | 挿入モードからノーマルモードへ |
| `Ctrl+Enter` / `Ctrl+s` | 依頼を送信。下書きならセッションを開始。挿入・ノーマルの両モードで有効 |
| `Enter` | 挿入モードでは改行。送信には `Ctrl+Enter` を使う |
| `Ctrl+c` | エージェントへ **Escape** を送る。Ctrl+c 自体の送信ではない |
| `Shift+Tab` | エージェントへ Shift+Tab を送る |
| `Tab` | 空の入力欄ではエージェントの提案を取り込む。内容がある場合は Neovim へ Tab を渡す |
| `Ctrl+p` / `Ctrl+n` | Insert: move up / down. Normal: recall the previous / next sent prompt |
| `Ctrl+b` / `Ctrl+f` | Insert and command line: move left / right |
| `Ctrl+a` / `Ctrl+e` | Insert and command line: move to the start / end of the line |
| `Ctrl+h` / `Ctrl+d` | Insert: delete before / under the cursor |
| `Ctrl+k` / `Ctrl+u` / `Ctrl+w` | Insert: delete to line end / line start / previous word |
| `Alt+b` / `Alt+f` | Insert: move one word back / forward |
| `Mod+i` | 添付画像を選択する。画像選択中のキーは後述 |
| `Ctrl+g p` / `Ctrl+g P` | **送信前の下書きのみ**：次 / 前のエージェントプロファイルへ切り替え。挿入モードでも使える |

`Ctrl+Enter`、`Ctrl+c`、`Shift+Tab`、`Tab`、`Ctrl+p`、`Ctrl+n` は
入力用 Neovim の標準マッピングです。Neovim 側の設定で変更できます。
補完候補が表示されている間は `Tab` / `Shift+Tab` / `Ctrl+p` / `Ctrl+n` は補完操作になります。
送信先のセッションがない下書きでは、エージェントへ送るためのキーは Neovim に渡ります。

## コンソール：エージェントへ操作を送る

セッション上側の Console の**ライブ表示中**に使います。
シェル、許可待ち、エージェント自身のダイアログ、DIRECT、出力閲覧中はキーの扱いが異なります。

| キー | 操作 |
| --- | --- |
| `i` / `a` / `I` / `A` / `o` / `O` | 入力欄へ移り、そのキーを渡す |
| `Enter` / `Ctrl+Enter` | エージェントへ Enter を送る |
| `ArrowUp` / `Ctrl+p` | 前のプロンプト履歴を入力欄へ取り込む |
| `ArrowDown` / `Ctrl+n` | 次のプロンプト履歴を入力欄へ取り込む |
| `ArrowLeft` / `ArrowRight` | エージェントへそのキーを送る |
| `Tab` | エージェントへ送る。ただし **Claude Code では入力欄へ移動**。この例外は閲覧中も有効 |
| `Shift+Tab` / `F2` / `Ctrl+l` / `Ctrl+o` / `Ctrl+t` / `Ctrl+_` | エージェントへそのキーを送る |
| `Ctrl+-` | エージェントへ Ctrl+_ を送る |
| `Ctrl+c` | エージェントへ **Escape** を送る |
| `g Ctrl+c` | エージェントへ **Ctrl+c 自体**を送る |
| `Ctrl+g Ctrl+o` | 次の1キーだけ、割り当てを通さず送る。Mod / Command の共通操作は除く |
| `Ctrl+g i` / `Ctrl+g Ctrl+i` | DIRECT に入り、キーを直接送る |
| `X` | 確認後にセッションを終了 |
| `Ctrl+q .` | エージェントへ Ctrl+q 自体を送る |

DIRECT は `Esc` で解除します。DIRECT 中も `Ctrl+c` は Escape の送信です。
`Mod` / Command の共通操作は使えますが、`Ctrl+q` の画面操作は直接送信されます。

## コンソール：出力を Neovim で読む

| キー | 操作・条件 |
| --- | --- |
| `Ctrl+q [` | コンソールの閲覧を開始。セッションの入力欄からも、シェルや許可待ち画面でも使える |
| `j` / `k`、`Ctrl+d` / `Ctrl+u`、`/`、`v`、`y` など | 閲覧用 Neovim の移動・スクロール・検索・選択・ヤンク。ヤンクはクリップボードへコピー |
| `g g` | 先頭へ。エージェント自身がスクロールを管理する場合は、その画面も先頭へ送る |
| `q` / `Esc` / `G` | **ノーマルモードで**閲覧を終え、ライブ表示へ戻る |
| `i` / `a` / `I` / `A` / `o` / `O` | **ノーマルモードで**入力欄へ。シェルや許可待ちなど、入力欄を使わない状態ではライブ表示へ戻る |

通常のセッションのコンソールでは、未割り当てのキー（`j` や `/` など）からも閲覧を始められます。
閲覧中も出力は更新されます。閲覧を終えるか入力欄に移ると最新の出力へ戻ります。
閲覧専用なので `:`、Ex モード、Neovim 自体の終了・ウィンドウ操作は使えません。

## 画面移動・分割

ここでいう「画面」は、同じタブ内の分割と左右のパネルを指します。
`Ctrl+w` は中の Neovim などが使うため、Tsumugi の画面操作は `Ctrl+q` から始めます。

| キー | 操作 |
| --- | --- |
| `Ctrl+q h` / `Ctrl+q j` / `Ctrl+q k` / `Ctrl+q l` | 左 / 下 / 上 / 右へ移動。h / j / k / l の代わりに矢印キーでも同様 |
| `Ctrl+q q` / `Ctrl+q Q` | 次 / 前の画面へ順番に移動 |
| `]]` / `[[` | 同じく次 / 前の画面へ循環移動(サイドバー → 中央 → 詳細パネル → サイドバー)。サイドバー・詳細パネル・ビューアー・セッションのコンソールと読み取り、入力欄のノーマルモードで使える。入力中の入力欄、全キーを受け取る Neovim やシェルでは、それぞれのキーのまま |
| `Ctrl+q t` / `Ctrl+q b` | 最初 / 最後の画面へ。表示中ならツリー / 詳細パネル |
| `Ctrl+q p` | 直前にフォーカスがあった画面へ戻る |
| `Ctrl+q v` / `Ctrl+q s` | 左右 / 上下に分割。同じ内容を表示する画面を追加 |
| `Ctrl+q n` | 上下に分割し、新しい画面に新規セッションの下書きを開く |
| `Ctrl+q i` | 応答待ち・失敗・ターン完了の履歴を開く。`Ctrl+u` で既読 / 未読を切り替え、`Ctrl+a` で表示中をすべて既読にし、Enter で発生元のセッションへ移動 |
| `Ctrl+q c` | 今の分割画面を閉じる。タブ内の最後の画面ならタブを閉じる |
| `Ctrl+q o` | 今のタブ内の、ほかの分割画面を閉じる |
| `Ctrl+q H` / `Ctrl+q J` / `Ctrl+q K` / `Ctrl+q L` | 今の画面を左端 / 下端 / 上端 / 右端へ配置し直す |
| `Ctrl+q x` / `Ctrl+q r` | 分割内の画面を交換 / 巡回配置 |
| `Ctrl+q =` | 分割の大きさを均等にする |
| `Ctrl+q <` / `Ctrl+q >` | 今の画面の幅を狭く / 広くする |
| `Ctrl+q Plus` / `Ctrl+q -` | 今の画面の高さを増やす / 減らす |
| `Ctrl+q _` / `Ctrl+q \|` | 高さ / 幅を可能な限り広げる |
| `Ctrl+q T` | 今の分割画面を独立したタブへ移す |
| `Ctrl+q e` | 対応文書のビューアーと編集用 Neovim を切り替える |

セッションでは入力欄がコンソールの下にあります。上側から `Ctrl+q j` で入力欄へ、
下側から `Ctrl+q k` でコンソールへ移れます。シェルには入力欄がないのでそこには止まりません。

## タブ

| キー | 操作・条件 |
| --- | --- |
| `Ctrl+Tab` / `Ctrl+PageDown` / `Ctrl+q g t` | 次のタブ |
| `Ctrl+Shift+Tab` / `Ctrl+PageUp` / `Ctrl+q g T` | 前のタブ |
| `Cmd+}` / `Cmd+{` | macOS：次 / 前のタブ |
| `Mod+1`〜`Mod+8` / `Ctrl+q 1`〜`Ctrl+q 8` | 中央の指定番号のタブへ。番号が数を超えると最後へ |
| `Mod+9` / `Ctrl+q 9` | 中央の最後のタブへ |
| `Ctrl+q g Tab` | 中央で直前に表示していたタブへ |
| `Ctrl+Shift+PageUp` / `Ctrl+q g <` | 中央のタブを左へ並べ替える |
| `Ctrl+Shift+PageDown` / `Ctrl+q g >` | 中央のタブを右へ並べ替える |
| `Ctrl+q m 1`〜`Ctrl+q m 9` | 今の中央タブの分割構成を指定タブへまとめる。9 は最後のタブ |
| `Ctrl+q M` / `Ctrl+q m m` | 今の中央タブを直前のタブへまとめる。なければ隣のタブへ |
| `Mod+w` | 中央のタブと、その中の分割画面を閉じる |

次 / 前のタブ操作は、右の詳細パネルにフォーカスがあるときだけ詳細パネル内のタブが対象です。
**タブ・分割・アプリのウィンドウを閉じても、セッションやターミナルは動き続けます。**
プログラムを終了するには `Mod+Backspace` やセッション行の `X` を使います。

## 左サイドバー：Tree / Agents

Tree と Agents の一覧にフォーカスがあるときのキーです。絞り込みの入力中は文字として入力されます。

| キー | 共通操作 |
| --- | --- |
| `Tab` / `Shift+Tab` | Tree と Agents のフォーカスを切り替える |
| `]]` / `[[` | 次 / 前のウィンドウへ。サイドバー → 中央 → 詳細パネル → サイドバーと循環する |
| `j` / `ArrowDown`、`k` / `ArrowUp` | 次 / 前の行 |
| `g g` / `G` | 最初 / 最後の行 |
| `Enter` / `o` | 選択項目を開く。折りたたまれた行では展開などを行う |
| `s` / `v` / `t` | 選択項目を上下分割 / 左右分割 / 新規タブで開く |
| `n` | 選択した作業場所に新規セッションの下書きを開く |
| `i` / `a` | 入力欄へ移り、そのキーを渡す |
| `X` / `R` | 選択セッションを確認後に終了 / 名前変更 |
| `y` | 選択したパスやセッション名などをコピー |
| `/` | 現在の一覧を絞り込む。`Enter` で確定、`Esc` で解除 |
| `w` / `r` | セッション・作業場所のピッカー / 状態の再取得 |

### Tree だけのキー

| キー | 操作・条件 |
| --- | --- |
| `l` / `L` / `Shift+Enter` / `Ctrl+Enter` | `Enter` と同じ、開く・展開する操作 |
| `h` | 折りたたむ、または親の行へ移動 |
| `$` / `e` | 選択した作業場所にシェル / Neovim を開く |
| `O` | 保存済み会話の再開ピッカー |
| `x` | 選択セッション・ターミナル・ファイルの表示を閉じる。プログラムは動き続ける |
| `g x` | 選択した Pull Request / Issue をブラウザーで開く |
| `A` | フォルダーをツリーに追加するピッカー |
| `!` | セッションのない worktree も表示 / 非表示。**ファイル選択中は隠しファイルの切り替え** |
| `N` / `K` | 選択場所に新規ファイル / ディレクトリを作成。名前を入力して確定 |
| `}` / `{` | 次 / 前のワークスペースのセッションへ |

### Agents だけのキー

| キー | 操作 |
| --- | --- |
| `l` / `ArrowRight` | セッションの親子グループを展開、または最初の子へ移動 |
| `h` / `ArrowLeft` | グループを折りたたむ、または親へ移動 |
| `g t` | 選択セッションを Tree に表示。Tree の絞り込みを解除し、該当パスを展開 |

### ファイルツリーでファイル・ディレクトリを選択中

この状態では次のキーが Tree の同じキーより優先されます。ピッカーのディレクトリツリーでも使えます。

| キー | 操作 |
| --- | --- |
| `j` / `k`、`ArrowDown` / `ArrowUp` | 次 / 前のファイル・ディレクトリ |
| `l` / `ArrowRight` | ディレクトリを開いて子へ。Tree のファイルなら開く |
| `h` / `ArrowLeft` | 折りたたむ、または親ディレクトリへ |
| `Enter` | Tree ではファイルを開く / ディレクトリを開閉。ピッカーでは選択ディレクトリを決定 |
| `!` | `.` で始まる隠しファイル・ディレクトリの表示切り替え |

## 右の詳細パネル

| キー | 操作・条件 |
| --- | --- |
| `Tab` | 詳細パネルの次のタブ |
| `Shift+Tab` | 詳細パネルの前のタブ |
| `]]` / `[[` | 次 / 前のウィンドウへ(循環) |
| `1`〜`9` | 詳細パネルの指定番号のタブへ |
| `j` / `k`、`ArrowDown` / `ArrowUp` | 一覧の次 / 前の行。文書表示ならスクロール |
| `g g` / `G` | 一覧の最初 / 最後。文書表示なら先頭 / 末尾 |
| `Ctrl+d` / `Ctrl+u` | 半ページ下 / 上へスクロール |
| `Esc` / `Backspace` | 開いた項目から元の一覧へ戻る |
| `y` | Overview の選択リンクの URL またはファイルパスをコピー |
| `a` | プロジェクトの resources にパスや URL を追加するシートを開く |
| `e` / `D` | 選択中の Pinned のラベル・メモを編集 / resources から外す |
| `p` | 選択中のリンク・ファイル・画像を resources に保存 |

詳細パネル自身の割り当ての後に Tree の割り当ても参照されます。
たとえば `Enter` で選択行を開けます。Resources の画像は `s` / `v` / `t` で分割・タブにも開けます。

## ビューアー：文書・画像・PDF・動画

中央のビューアーにフォーカスがあるときに使います。ファイルの種類に対応した操作だけが働きます。

| キー | 操作 |
| --- | --- |
| `j` / `k`、`ArrowDown` / `ArrowUp` | 下 / 上にスクロール |
| `Ctrl+d` / `Ctrl+u` | 半ページ下 / 上にスクロール |
| `g g` / `G` | 先頭 / 末尾へ |
| `]]` / `[[` | 次 / 前のウィンドウへ(循環) |
| `Plus` / `=` / `-` / `0` | 拡大 / 拡大 / 縮小 / 画面に収める |
| `J` / `K` | PDF の次 / 前のページ |
| `Space` | 動画を再生 / 一時停止 |
| `h` / `l` | 動画の巻き戻し / 早送り |
| `y` | 表示中のファイルパスをコピー |
| `g x` | 対応する Pull Request / Issue をブラウザーで開く |
| `e` | 対応文書を Neovim で編集。`Ctrl+q e` で表示を切り替えられる |
| `q` | 今の分割画面を閉じる |

## 画像の拡大表示（ライトボックス）

セッションの画像を画面に重ねて拡大表示している間の操作です。

| キー | 操作 |
| --- | --- |
| `l` / `ArrowRight`、`h` / `ArrowLeft` | Resources の次 / 前の画像。端まで行くと巡回 |
| `Plus` / `=` / `-` / `0` | 拡大 / 拡大 / 縮小 / 画像全体を中央に表示 |
| `H` / `L` / `K` / `J` | 画像の表示位置を左 / 右 / 上 / 下へ移動 |
| `Esc` / `q` | 拡大表示を閉じる |

## ピッカー・確認・キーヘルプ

セッション選択、会話再開、右クリックメニュー、確認ダイアログ、環境追加、キーヘルプの操作です。
入力欄のあるピッカーでは `j` / `k` / `q` は検索文字になります。

| キー | 操作・条件 |
| --- | --- |
| `Esc` / `Ctrl+c` / `q` | 閉じる。確認ダイアログなら「いいえ」。文字入力中の q は入力 |
| `Ctrl+n` / `Ctrl+j` / `ArrowDown` / `Tab` / `j` | 次の候補。キーヘルプでは下へスクロール |
| `Ctrl+p` / `Ctrl+k` / `ArrowUp` / `Shift+Tab` / `k` | 前の候補。キーヘルプでは上へスクロール |
| `Enter` | 選択候補を決定。確認ダイアログなら「はい」 |
| `y` / `n` | **確認ダイアログのみ**：「はい」/「いいえ」 |
| `Ctrl+d` / `Ctrl+u` | キーヘルプなど、対応する表示を半ページ下 / 上へスクロール |
| `F1` | F1 で開いたキーヘルプを閉じる |

セッション・作業場所のピッカーでは、次の専用キーも使えます。
ここは `Mod` ではなく、macOS でも **Ctrl** を使います。

| キー | 操作・条件 |
| --- | --- |
| `Ctrl+f` | 検索一覧とディレクトリツリーの切り替え |
| `Ctrl+s` / `Ctrl+e` | 選択候補の場所にシェル / Neovim を開く |
| `Ctrl+t` | 選択候補の場所を Tree に追加 |
| `Ctrl+a` | **会話再開ピッカーのみ**：現在のディレクトリ / 全ディレクトリで検索する切り替え |

クローン候補では `Enter` はクローン後にセッションの下書きを開き、
`Ctrl+s` / `Ctrl+e` / `Ctrl+t` はクローン後に対応する操作を行います。

## 添付画像の選択中

入力欄で `Mod+i` を押して画像を選択した後のキーです。ビューアーやライトボックスとは別です。

| キー | 操作 |
| --- | --- |
| `h` / `ArrowLeft`、`l` / `ArrowRight` | 前 / 次の添付画像を選択 |
| `Tab` / `Shift+Tab` | 次 / 前の添付画像。端まで行くと巡回 |
| `x` / `Delete` / `Backspace` | 選択画像を添付から外す |
| `Esc` / `Enter` | 画像の選択を終える |

## 連続操作とキー設定

タブ移動や画面サイズ調整など、連続操作に対応したキー列は最後のキーだけで繰り返せます。
たとえば `Ctrl+q g t t t` は次のタブへ3回進みます。途中の `T` で前へ戻ることもできます。
画面左下が `REPEAT` の間だけ有効で、ほかの操作や文字入力で解除されます。
どのアクションが対応するかは [生成リファレンス](spec/reference/keys.md#actions) にあります。

Settings のキー設定では、アクション別・画面別に割り当てを確認・変更・初期化できます。
設定ファイルを直接編集する場合は、ウィンドウを動かしているコンピューターの
`$TSUMUGI_KEYS`、未指定なら `$XDG_CONFIG_HOME/tsumugi/keys.toml`
（XDG_CONFIG_HOME が未指定なら `~/.config/tsumugi/keys.toml`）を使います。
変更は自動で読み直され、誤りがある場合は直前の有効な設定が維持されます。
入力用 Neovim のマッピングは Neovim 側で設定します。

この一覧の対応元は `crates/core/src/keymap/defaults.toml`、
入力欄は `crates/nvim/lua/tsumugi/keys.lua`、閲覧終了は
`crates/core/src/console/reader.rs`、ピッカーは `crates/core/src/picker.rs`、
添付画像は `crates/core/src/prompt/images.rs` です。
既存の日本語総合ガイドは [guide.ja.md](guide.ja.md)、英語の全キー一覧は
[spec/reference/keys.md](spec/reference/keys.md) にあります。
